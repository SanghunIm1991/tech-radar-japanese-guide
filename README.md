# tech-radar-japanese-guide

Thoughtworks が発行する Technology Radar に載った技術を、IT エンジニア向けに日本語で解説する、**非公式**の資料集です。専門分野を問わず読めるように用語をやさしく説明しつつ、システムアーキテクトの観点（トレードオフ・採用の判断）も扱います。

> **ご注意**
>
> - このリポジトリは個人が作った非公式の資料です。Thoughtworks とは関係がありません。Thoughtworks による翻訳・承認・推奨を受けたものでもありません。
> - Technology Radar の文章は翻訳・転載していません。技術そのものの解説は、各技術の公式ドキュメント等をもとに独自に書いています。Radar での評価は、短い要旨と公式のページへのリンクにとどめています。
> - 解説は **Claude Code（AI）が作成**しています。状態が「公開承認済み」の解説は人が公開を承認していますが、**内容の正確さを人が個別に確かめてはいません**。「下書き」の解説は承認前の作成中のものです。どちらかは、各解説の冒頭の「状態」で示しています。もっともらしい誤りが混ざりうるので、技術を選ぶ際は必ず一次情報を確かめてください。

## 目的

技術選定の候補を広く浅く知るための入口です。1つの技術を15分程度で読める基本的な内容にとどめ、深く調べるための一次情報へのリンクを付けています。

## Technology Radar の読み方

Technology Radar は、Thoughtworks が実際の案件での経験をもとに技術を評価し、約半年ごとに発行しているものです。公式のサイトは https://www.thoughtworks.com/radar です。評価の対象の1つ1つを「blip」と呼びます。各 blip は、4つの象限と4つのリングで分類されます。

**象限（技術の種類）**

| 象限 | このリポジトリでの説明 |
|---|---|
| Techniques | 開発や運用の進め方・手法 |
| Tools | 開発や運用で使う道具（ソフトウェア） |
| Platforms | アプリケーションを載せて動かす基盤・サービス |
| Languages & Frameworks | プログラミング言語・フレームワーク・ライブラリ・仕様 |

**リング（採用を勧める度合い。上ほど強い）**

| リング | このリポジトリでの説明 |
|---|---|
| Adopt | 多くの場面で採用してよいと評価されている |
| Trial | 実際のプロジェクトで試す価値があると評価されている |
| Assess | 調べて、自分たちに合うかを検討する価値があると評価されている |
| Caution | 採用に注意が要ると評価されている（以前の版では「Hold」） |

表の説明は、このリポジトリが自分の言葉で書いた要約です。正確な定義は公式のサイトを参照してください。Radar は Thoughtworks という1社の見解で、業界全体の総意ではありません。

## 各解説の読み方

1つの技術につき、次の見出しをそろえています。

1. 一言でいうと
2. 解決する課題（なぜ生まれたか）
3. 仕組みの概要
4. アーキテクチャ上の位置づけとトレードオフ
5. 採用を判断するときの観点
6. 関連技術・代替技術
7. Radar での扱い（Thoughtworks の評価の要旨とリンク）
8. 深掘りするときの一次情報
9. 確認日

末尾には、専門用語をやさしく説明した用語集を付けています。1〜6と8は、技術そのものの解説です（版が変わってもあまり古くなりません）。7は、その版の時点での Radar の評価です（版ごとに変わります）。
